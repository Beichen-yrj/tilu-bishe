# 数据库初始化说明

> 配套脚本在 `scripts/数据库初始化包/`：`初始化数据库.bat`、`init_db.sql`（本文件由该目录下的 `使用说明.txt` 整理而来）。
> 每位队友只需执行一次。

## 最快方式：双击

1. 确认本机 MySQL 已启动（默认端口 3306，账号 root，密码 123456）。
2. 双击 `初始化数据库.bat`。
3. 窗口中看到 `[成功] 数据库初始化完成` 即可（会同时打印表数量、管理员数量与账号清单）。
4. 管理员账号：`admin / admin123456`（登录后可在"个人中心"修改密码）。

## 如果提示找不到 mysql.exe

按窗口提示，把 `mysql.exe` 的完整路径粘贴进去回车即可，例如：

```text
D:\MySQL\MySQL Server 8.0\bin\mysql.exe
```

或改用图形客户端（任选一个）：

- Navicat / MySQL Workbench / DBeaver 打开 `init_db.sql`，全选后整体执行
- 连接参数：主机 `127.0.0.1`　端口 `3306`　账号 `root`　密码 `123456`

## 如果 MySQL 账号密码或端口不是 3306 / root / 123456

用记事本打开 `初始化数据库.bat`，修改最上方的 `MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_USER` / `MYSQL_PWD` 四个参数；
并且同步修改 `backend\.env` 里的 `DATABASE_URL` 与 `backend\app\config.py` 的默认值，再重启后端。

## 脚本做了什么

- 创建数据库 `rail_safety`（utf8mb4，unicode_ci）
- 创建 5 张表：
  1. `users` 账号、显示名、头像、密码摘要（bcrypt）、角色
  2. `auth_sessions` 登录会话：令牌标识、有效期、注销时间
  3. `assessments` 风险快速评估任务：检测数据、静态检查结果、风险结论与措施
  4. `hazard_assessments` 现场隐患排查评估记录：场站/环节/维度、检测数据与标准值、隐患定级（L、C、R）、隐患描述与整改措施、现场照片、整改照片、复核结论、整改日志、流程版本
  5. `feedbacks` 意见反馈：用户提交内容、管理员回复与时间
- 创建管理员账号：`admin / admin123456`
- 可以重复执行：表已存在不会重建，账号已存在只校正角色，不会清空既有数据

## 如果你是旧版本库（只有 4 张表）

直接重新执行本脚本即可，脚本会自动补建缺少的 `hazard_assessments` 表，
已有表与数据不受影响（`CREATE TABLE IF NOT EXISTS`，不会重建、不会清空）。

## 可选：把自己已有的账号提升为管理员

在客户端里执行（把 `username` 换成你的账号）：

```sql
USE rail_safety;
UPDATE users SET role = 'admin', updated_at = NOW() WHERE username = '你的账号';
```

## 可选：查看执行结果

```sql
USE rail_safety;
SELECT table_name FROM information_schema.tables WHERE table_schema='rail_safety';
SELECT id, username, display_name, role, is_active FROM users ORDER BY id;
```

## 执行完成后启动服务

- 后端：`cd backend` → `.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000`
- 前端：`cd daima` → `npm run dev` → 浏览器打开 <http://localhost:5173>
- 也可直接双击项目根目录的 `启动项目.bat` 一键启动前后端（后端路径为 `web\daima\backend`）
