# 文档索引

本目录（`web/docs`）集中存放项目全部文档，按用途分为两个分类文件夹：

- `指南/`：使用、部署与运维类文档（怎么用、怎么装、怎么维护）
- `设计/`：需求、架构与开发类文档（要做什么、怎么实现）
- `参考资料/`：课题原始材料，仅作背景参考，不作为实现依据

源码与工具按用途分目录：`frontend/`（React + Vite 前端）、`backend/`（FastAPI 后端）、`deploy/`（`backup.sh`、`update.sh`）、`scripts/`（`启动项目.py` 与 `数据库初始化包/`）、`docs/图片素材/`（图片素材）。
