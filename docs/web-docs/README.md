# web-docs · 网站文档

本目录存放 `web/`（网站部分）的全部文档，按用途分类：

- `指南/`：使用类文档（怎么用、怎么建库）
- `设计/`：需求、架构与开发类文档（要做什么、怎么实现）
- `参考资料/`：课题原始材料，仅作背景参考，不作为实现依据
- `图片素材/`：需求文档引用的原始截图（与前端 `public/` 重复的副本已清理，仅保留未入前端的原始素材）

代码目录：`web/frontend/`（React + Vite 前端）、`web/backend/`（FastAPI 后端）、`web/scripts/`（`启动项目.py` 与 `数据库初始化包/`）。
